# PlanFlow AI 测试计划

## 测试策略

测试重点放在让项目区别于普通 Todo 的部分：

- 每周可用时间校验
- 飞书忙闲冲突扣除
- 排程算法
- 复盘顺延
- AI 输出校验
- API 契约
- 前端主流程
- 日历导出

## 单元测试

### 可用时间校验

用例：

- 接受一个有效星期时间段。
- 接受同一天多个不重叠时间段。
- 接受某些星期没有时间段。
- 拒绝结束时间早于开始时间。
- 拒绝开始时间等于结束时间。
- 拒绝重叠时间段。
- 拒绝非法星期值。

### 排程器

用例：

- 任务只排入扣除忙碌时间后的真实可用时间。
- 跳过禁用星期。
- 使用同一天的多个时间段。
- 不与忙碌时间冲突。
- 把长任务拆分到多个日程。
- 优先使用更早的可用时间段。
- 可用时间不足时返回未排完分钟数。
- 相同输入产生确定性输出。

### 日历 provider 和真实可用时间

用例：

- MockFeishu 返回指定日期范围内的忙碌时间。
- 忙碌时间完全覆盖可用时间时，该时间段不可用。
- 忙碌时间位于可用时间中间时，可用时间被切成前后两段。
- 配置 15 分钟缓冲后，忙碌时间结束后的 15 分钟不可排学习任务。
- 忙碌时间和可用时间没有交集时，可用时间保持不变。

### 复盘顺延

用例：

- 已完成复盘不会创建顺延日程。
- 部分完成会把剩余分钟数重新排入后续真实可用时间。
- 未完成会把原日程时长重新排入后续真实可用时间。
- 自定义缓冲时间会影响顺延后的最早开始时间。
- 跳过会触发顺延并记录原因。
- 截止日期前容量不足时返回警告。

### AI 输出校验

用例：

- 接受有效生成任务。
- 拒绝缺少标题的任务。
- 拒绝预计分钟数非正数的任务。
- 拒绝空验收标准。
- 当生成总分钟数和目标偏差过大时给出警告。

### 日历导出

用例：

- 为日程生成有效 `.ics` 内容。
- 事件 `summary` 字段包含任务标题。
- 事件 `description` 字段包含计划标题和验收标准。
- 没有日程时清晰失败。

## API 测试

### `POST /api/plans`

用例：

- 使用有效可用时间创建计划。
- 支持设置 `rescheduleBufferMinutes`。
- 拒绝非法截止日期。
- 拒绝空可用时间。
- 拒绝重叠时间段。

### `POST /api/plans/:planId/generate`

用例：

- 生成任务和日程。
- 返回模拟飞书忙碌时间。
- 可用时间不足时返回警告。
- 计划不存在时返回 404。

### `GET /api/plans/:planId/busy-slots`

用例：

- 返回指定日期范围内的忙碌时间。
- 计划不存在时返回 404。

### `GET /api/plans/:planId`

用例：

- 返回计划详情，包含任务、日程、可用时间和进度。
- 计划不存在时返回 404。

### 状态更新

用例：

- 更新任务状态。
- 更新日程状态。
- 拒绝非法状态。

### 复盘

用例：

- 提交已完成复盘。
- 提交部分完成复盘并创建顺延日程。
- 提交未完成复盘并创建顺延日程。
- 拒绝非法复盘结果。
- 容量不足时返回警告。

### 日历导出

用例：

- 返回 `text/calendar`。
- 计划没有日程时返回 409。

## 前端验证

手动浏览器检查：

- 计划创建正常流程。
- 每周可用时间新增和删除。
- 错误时间段的校验提示。
- 生成计划加载状态。
- 生成计划错误状态。
- 桌面端日历视图。
- 移动端日历视图。
- 忙碌时间展示。
- 标记日程完成。
- 提交复盘。
- 查看顺延后的日程。
- 导出 `.ics`。

## 构建验证

每个阶段声称完成前：

- 运行全部单元测试。
- 运行 API 测试。
- 运行类型检查。
- 运行生产构建。
- 检查 Git 状态。
